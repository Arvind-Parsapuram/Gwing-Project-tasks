# 🎮 Python Mini Games & Projects

A collection of beginner-friendly Python projects built to practice programming concepts such as loops, conditional statements, functions, randomization, user input, and file handling.

## 📌 Projects Included

### 🎯 1. Number Guessing Game
A fun console-based game where the computer generates a random number and the player has to guess it.

**Features**
- Random number generation
- User input validation
- Hint messages (Too High / Too Low)
- Tracks attempts until the correct guess

**File**
- `guessing_game.py`

---

### ❓ 2. Quiz Game
A simple quiz application that asks multiple-choice or predefined questions and calculates the final score.

**Features**
- Multiple questions
- Score calculation
- Instant feedback
- Final result display

**File**
- `quiz_game.py`

---

### ✊✋✌️ 3. Rock Paper Scissors
Play Rock, Paper, Scissors against the computer.

**Features**
- Random computer choice
- Win/Lose/Draw detection
- Interactive gameplay
- Replay support (if implemented)

**File**
- `rock_paper_scissors.py`

---

### 🏰 4. Choose Your Own Adventure Game
A text-based adventure game where every decision changes the storyline.

**Features**
- Multiple story paths
- Decision-based gameplay
- Interactive text adventure
- Different possible endings

**File**
- `haunted_castle.py`

---

### 📈 5. House Price Prediction
A beginner Machine Learning project that predicts house prices using Linear Regression.

**Features**
- CSV dataset
- Data preprocessing
- Linear Regression model
- Price prediction

**Files**
- `house price prediction.py`
- `house_price_regression.csv`

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Gwing-Project-tasks.git
```

2. Navigate to the project folder

```bash
cd Gwing-Project-tasks
```

3. Run any project

Example:

```bash
python guessing_game.py
```

or

```bash
python quiz_game.py
```

or

```bash
python rock_paper_scissors.py
```

or

```bash
python haunted_castle.py
```

or

```bash
python "house price prediction.py"
```
